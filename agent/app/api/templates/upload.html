The file is only read here. Nothing is saved until you have seen the values on the next screen and confirmed them.

CSV or JSON is read exactly as written. A PDF, photo or scan has to be read by the AI, which can misread it — you will be shown every value to check.

What the file should contain

A CSV needs a header row and one row per bill line:

line_no,description,product_code,qty,unit_price_tk,amount_tk
1,Pro X industrial unit,PRO-X,10,100.00,1000.00
2,Pro Y industrial unit,PRO-Y,5,100.00,500.00

product_code may be left blank — the AI will try to match those lines to the purchase order, and anything it is unsure about goes to review rather than being guessed. If amount_tk is missing it is computed as quantity x unit price and flagged.
